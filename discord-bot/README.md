# Discord bot starter

This is a blank Node.js project for your Discord.js v14 bot. No bot behavior or
webpage is included.

## Run it

From this folder:

```sh
npm install
npm start
```

`npm start` runs `index.js`. Replace its placeholder with your bot code.

## Keep credentials private

Add your token in Replit's Secrets as `DISCORD_TOKEN`, then read it in your code
with `process.env.DISCORD_TOKEN`. Do not paste the token into `index.js` or
commit it in a `.env` file.
